# Agency Platform

A full-stack digital agency platform with frontend, mobile app, backend API, and CRM admin dashboard.

## Project Structure

- **01-frontend-nextjs**: Next.js frontend application
- **02-mobile-app**: Mobile application (React Native)
- **03-backend-server**: Node.js/Express backend API with MongoDB
- **04-crm-admin**: CRM admin dashboard

## Tech Stack

### Frontend
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion

### Backend
- Node.js
- Express
- MongoDB (Mongoose)
- TypeScript

### Mobile
- React Native

## Getting Started

### Frontend Setup
```bash
cd 01-frontend-nextjs
npm install
npm run dev
```

### Backend Setup
```bash
cd 03-backend-server
npm install
npm run dev
```

### Mobile App Setup
```bash
cd 02-mobile-app
npm install
npm run android  # or npm run ios
```

### CRM Admin Setup
```bash
cd 04-crm-admin
npm install
npm run dev
```

## Features

- Multi-country landing pages
- Service-specific pages (Real Estate, E-commerce, Cloud, Marketing, Placements, SEO)
- Contact forms and lead capture
- Dynamic pricing
- SEO schema generation
- CRM system for lead management
- Mobile app for on-the-go access

Each project requires its own `.env` file. Refer to individual project documentation for specific environment variables.
